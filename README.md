# Bangladesh Railway Ticket Assistant

Chrome Manifest V3 personal helper for the Bangladesh Railway e-ticket workflow.

## v2.1.0 features
- Quick Search: From, To, Date, Class, Passenger quantity and preferred train
- Saved routes and repeat journey
- Multiple passenger profiles with edit/delete
- Family/group profiles with selectable members
- Passenger and search form filling where matching fields are detected
- Smart form checker for required/relevant fields
- Manual booking checklist and progress
- Journey reminders
- Journey history and notes
- Local backup/restore
- Dark mode
- Local PIN lock for the extension UI
- Keyboard shortcuts
- Clear editable fields
- Official Railway shortcut

## Install
1. Download this repository as ZIP and extract it.
2. Open Chrome and visit `chrome://extensions`.
3. Turn on **Developer mode**.
4. Click **Load unpacked**.
5. Select the extracted extension folder.
6. After an update, click **Reload** on the extension card.

## Important
The helper does not solve CAPTCHA, bypass OTP, automate payment, bypass queues, defeat anti-bot controls, or submit protected booking steps. Review all filled information yourself and complete protected steps manually.

The official Bangladesh Railway guidance describes entering journey date, origin, destination, train, class and ticket quantity before proceeding through the protected booking flow.

Official site: https://eticket.railway.gov.bd/
