# Bangladesh Railway Ticket Assistant

Chrome Manifest V3 helper for your own Bangladesh Railway ticket workflow.

## Features
- Quick Search: From, To, Date, Class, Passenger quantity
- Multiple passenger profiles
- Auto Fill
- Save Search
- Clear editable fields
- Export / Import profiles
- Dark mode
- Official Railway shortcut

## Install
1. Download this repository as ZIP and extract it.
2. Open Chrome and visit chrome://extensions
3. Turn on Developer mode.
4. Click Load unpacked.
5. Select the extracted folder.

The extension does not bypass CAPTCHA, OTP, payment, queues, or other security controls. Always review information and complete protected steps manually.

Official site: https://eticket.railway.gov.bd/
